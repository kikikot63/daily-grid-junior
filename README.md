# The Daily Grid — Junior

Twenty English crossword puzzles, with offline caching and home-screen installation support.

## GitHub Pages

Publish the `main` branch, folder `/ (root)`, from Settings → Pages → Deploy from a branch. No build tools, database, paid hosting, or custom domain are required.

Open the published HTTPS address and wait for **Ready offline · 20 puzzles** before disconnecting. On iPhone, open the site in Safari and choose Share → Add to Home Screen, then open the new icon once while connected.

Game progress is stored in the current device and browser. It does not sync between devices or site addresses.

The included font licenses are in the `*-OFL.txt` files.
